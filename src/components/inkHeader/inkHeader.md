# InkHeader Component

The InkHeader component is the main application header that displays the brand logo and navigation back to the home page.

## Features

- Responsive header with brand logo and name
- Navigation link to home page
- Gradient background with border
- Fixed z-index for proper stacking

## Usage

```vue
<InkHeader />
```

## Props

Currently, this component does not expose any props. It renders a fixed header with the InKCre brand.

## Design

The header follows the minimalist design philosophy with:

- Clean, monochromatic styling
- Gradient background from background to background-muted color
- Uppercase brand name with letter spacing
- Mobile-responsive padding
